# CCNA Lab 02 - IP Addressing

## Overview

This lab demonstrates basic IPv4 addressing using Cisco Packet Tracer.

Two PCs are connected through a switch and configured with IP addresses from the same subnet. Connectivity is verified using the `ping` command.

---

## Objectives

- Configure IPv4 addresses manually
- Configure subnet masks
- Configure default gateways
- Verify connectivity using ping

---

## Tools

- Cisco Packet Tracer
- GitHub
- Markdown

##  IP Configuration

| PC0 | 192.168.1.10 | 255.255.255.0 | 192.168.1.1 |
| PC1 | 192.168.1.20 | 255.255.255.0 | 192.168.1.1 |
